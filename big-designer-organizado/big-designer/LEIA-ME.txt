COMO O HTML, O CSS E O JAVASCRIPT SE LIGAM
Cada página chama o CSS no <head> e o JavaScript no fim do <body>:
  index.html     <link rel="stylesheet" href="css/index.css">      <script src="js/index.js"></script>
  pages/*.html   <link rel="stylesheet" href="../css/index.css">   <script src="../js/index.js"></script>
Dentro de pages/ o caminho começa por ../ (sobe uma pasta). O favicon segue a mesma regra.

COMO ABRIR NO PC
1. Extrai o ZIP completo. Não abras o index.html de dentro do zip: assim o CSS, o JS e as imagens não são encontrados e a página aparece sem estilo.
2. No VS Code abre a pasta big-designer e clica em Go Live (Live Server). O modelo 3D costuma precisar disto para carregar.

COMO ADICIONAR FOTOS DOS PROJECTOS
Guarda cada foto com o nome 1.jpg, 2.jpg ... 5.jpg na pasta do projecto. Aparecem sozinhas.

PUBLICAR NO GITHUB PAGES
1. Extrai o ZIP. Abre a pasta big-designer.
2. No repositório: Add file > Upload files. SELECCIONA TUDO o que está dentro da pasta (index.html + pastas) e ARRASTA para a página.
3. Commit. Depois Settings > Pages > Deploy from a branch > main / (root).
